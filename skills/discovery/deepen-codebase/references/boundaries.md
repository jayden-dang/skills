# Neighbor boundaries, rationalizations, red flags

Load when a neighbor skill might be the better fit, or when a rationalization
to skip foundation / encode a pick appears.

## What this is NOT

| Neighbor | Boundary |
|---|---|
| `interpret-session` | Model + stance — **theirs**. You explain; you do not pick. |
| `work-the-problem` | Multi-round tree + carry-back — **theirs** when a frame-change question must close. |
| `teach-pack` | Graded productions — **name** `/teach-pack` when sticky proof is needed. |
| `study-change` | One git-range HTML packet — **theirs**. |
| `tour-system` | System tours — **theirs**. Soft-name when the ask is atlas/tour/journey. |
| `research` | External owning-source note — **sub-skill** for material F2/F3/F4 claims. |
| `clarify-decisions` / `frame-change` | Product forks and ceremony — **theirs**. |

## Rationalizations

| Thought | Reality |
|---|---|
| "Paste already explains the design — skip F0" | Paste is a source claim. Foundation before delta |
| "They asked which option / no lecture" | Unranked delta only after foundation; name `/interpret-session` for a stance |
| "Demo in 20 minutes — skip foundation" | Thin the layer; keep order |
| "Standard practice is X" | Tier + source, or **inference** |
| "Cover every layer this turn" | One primary layer |
| "I know this stack from training" | Read F5; research F2–F4 when material |
| "Reuse last subject's checklist" | Re-derive must-know map |
| "Ranking options isn't recommending" | Ranking encodes preference. Unranked only |
| "I'll run teach-pack for them" | Name `/teach-pack`; user invokes |

## Red flags

Stop and re-read the Iron Laws if you recommend or rank a product option; say
"standard" without tier + source; open Delta before F0+F1 without
`foundation: explicitly_skipped`; reuse another domain's map; opine on repo
code without reading it; dump multiple Axis B layers in one turn; claim
learning complete; write tracked project files; auto-invoke a user-invoked
skill; skip the announce block; invent cells to complete a template.

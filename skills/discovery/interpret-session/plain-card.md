# The card the user can decide from

Every live-choice turn **is** this, after grounding. Companion language. Ordinary
sentences — a table cell is not a sentence. Old information at the start of a
unit, the point at the end. Compute the verdicts in `grounding.md` first; do not
render those four blocks on this turn.

## Order

After grounding, write in this order, then the Go deeper menu from `go-deeper.md`:

1. **Gist** — one sentence that distinguishes the options.
2. **To hold this card** — the connected parts, where the model stops, one diagram.
3. **One run** — 4–8 lines, named actor, today vs the pick.
4. **Choices and pick** — why those options exist, the pick, who it hits.
5. **Lock strip** — what `0` would freeze, including paste-vs-repo facts that move the pick.
6. **Fence** — one line this card does not decide.

A turn that opens on `### 1. Today`, a one-line analogy, Architect's read, or the
seven stance slots has skipped the card. Measured on a ten-card session
(Vietnamese, mermaid): every live-choice opened on `Hình dung` plus Today plus
three architect tables. The user typed "giải thích lại 1 cách dễ hiểu hơn về
card và lựa chọn của bạn", then skipped every Go deeper line except carry-back.

## Gist

One sentence. It is the fork, not a topic. "Nắp tủ đã lưu, không phải nắp cặp
đang gửi." If a reader only keeps this line, they can still tell the options apart.

## To hold this card

The minimum graph the question stands on — not a glossary, not the whole
platform. Four to seven pieces. Each maps `plain meaning → the part → the
canonical term`, then uses the term. Say how each piece **connects** to the next.

WHEN a prior lock exists, the first piece is the lock this card hangs off.

**Where the model stops** — one or two lines on the relation the picture maps,
and the place it does not. "Cặp = frame. Tủ = stored row. Native không có cặp."
A one-line analogy that is not used again is not this graph — measured,
`Hình dung: thùng xe khác két sắt` sat above Today and the user still asked.

**Draw that graph**, not the options. One picture, setup form, every node a fact
(limit, count, ordering), not just a name. Read `diagrams.md` and follow it.
`[!]` on the guarantee, `[*]` on what the pick changes.

## One run

Four to eight lines. A named person walks **this** graph: today, then under the
pick. Numbers from the code. The trap — the paste looks like a widen and is a
hide — lives here, not as a lecture. This is not the hop-2 `file:line` walk.

## Choices and pick

Why **these** options exist (a missing owner, Compat None, a lock already taken).
One line each: what someone using or running it would notice.

**I'd pick** — the shape, and the repo fact that decides it, in the same language
as the gist. A shape the repo points at that the paste did not name gets its own
line here, judged with the others; it loses when it loses.

**Not** — each loser, one line, on that same fact.

**Who it hits** — only the actors this card moves (learner, creator, app-dev,
platform). Skip the rest.

## Lock strip

What a `0` would freeze. Two to four paste-vs-repo disagreements that would
**move the pick**, each one sentence with `file:line`. If none, say the paste
matches the repo. Cost accepted. Numbers you derived stay unverified.

These are the Versus **Amend** lines, named here so a user who never takes a
depth hop still has them. A correction that arrives on hop 2 arrives too late.

## Fence

One line: this card does not decide X. Always. The paste's extra decision, if
any, is named here rather than smuggled into the lock.

## Writing

Rephrase without the new word, then use the word. Map relations, not attributes.
Do not quiz the user. Do not open on a drawing or an analogy before the gist.

# Neighbor boundaries, rationalizations, red flags

Load at setup and whenever a pick, skip-foundation, or neighbor-skill temptation
appears.

## What this is NOT

| Neighbor | Boundary |
|---|---|
| `interpret-session` | Fast stance + reply — **theirs** under time pressure. You go deep. |
| `deepen-codebase` | Pure foundation, no pick — **theirs** when nothing must close. |
| `/forge-prompt` | Vague ask → one prompt. Name it for the user to run. |
| `frame-change` / `clarify-decisions` | Main ceremony — feed via carry-back; do not run their checklists. |

## Rationalizations

| Thought | Reality |
|---|---|
| "Overview is enough; frame-change will finish it" | Close leaves or explicit defer |
| "They're in a hurry — skip foundation" | Time-boxed path is `/interpret-session`. Here: thin prose, keep order |
| "I'll just generate the full answer" | Articulate or record `delegated` |
| "Just solve / paste-ready now closes the root" | `delegated` skips articulation only — not foundation, not carry-back while leaves are open |
| "Chat memory is enough mid-loop" | Persist artifacts every changing turn |
| "Both options are fine — your call" | Name what you'd do and the flip condition |
| "I'll run run-spike / deepen for them" | Name the skill; user invokes |
| "Suggested code change → implement it" | Read-only; suggestion in carry-back only |

## Red flags

Stop if you rank options before F0/F1 without recorded skip; close root with
silent open leaves; manufacture options for a yes/no; end mid-solve with a
direction menu; opine on repo code without reading it; auto-invoke a
user-invoked skill; claim mastery; skip disk after a state-changing turn; write
tracked files or enact decisions; skip the announce block; treat "just solve"
as license for carry-back while ROOT is still open.

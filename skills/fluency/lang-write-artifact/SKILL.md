# Write artifact

## Role

REQUIRED: read sibling `ROLE.md` (coach default, produce-first, evidence gate, config paths).

## Iron Law

```
THE LEARNER WRITES THE FIRST DRAFT, UNAIDED.
SAME SHAPE EVERY WEEK, OR WEEKS DO NOT COMPARE.
CONTRAST VERSION COMES AFTER THEIR OWN REVISION, NEVER BEFORE.
```

## Recipe

1. **Shape is fixed for the cycle**; only the prompt's theme rotates. Same genre, same length band, same time limit, same medium. Read `artifact_shape` from the cycle note and hold it — a shape that drifts week to week destroys the comparison the artifact exists for.
2. The learner drafts under the time limit, unaided: no outline from the coach, no vocabulary supplied, no "just start me off". Questions during the attempt get a frame, not content.
3. REQUIRED SUB-SKILL: use `lang-diagnose-output` on the draft.
4. The learner revises from the diagnosis, themselves. Only after their revision exists, show a stronger version of one or two passages — labelled explicitly as **contrast**, never as the answer. Contrast shown early replaces their revision with copying.
5. File under `artifacts/` with: time taken, length, the shape, which forced-production capabilities appeared, and links to the diagnosis.
6. Name the **delta** against the same-shape artifact from earlier in the cycle: what is measurably different — error density, range of structures used, time taken, length at the same time limit. If nothing is comparable yet, say so; this is the baseline.

## Rationalizations

| Thought | Reality |
|---|---|
| "Give them an outline to save time" | The organisation is part of what is being measured |
| "Change the format, this one is stale" | A changed shape erases the only comparison in the system |
| "Show the strong version first as a model" | Then their revision is transcription, not production |
| "It's shorter than last week — don't mention it" | Length at a fixed time limit is one of the cleanest fluency signals there is |
| "Skip it, they did a lot of speaking this week" | Then the week has no comparable product and the cycle has a hole |

## Red flags

- Shape differs from `artifact_shape` in the cycle note
- Coach-supplied outline, opener, or vocabulary during the attempt
- Contrast version shown before the learner's own revision
- Artifact filed with no delta named and no baseline declared

## Done when

Artifact filed at the cycle's fixed shape, drafted unaided, diagnosed, revised by the learner before any contrast, with the delta against the previous same-shape artifact named or a baseline declared.

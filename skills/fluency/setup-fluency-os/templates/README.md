## The loop

```text
plan-cycle ──▶ run-session / run-voice-session ──▶ diagnose-output
     ▲                    │                              │
     │           study-word · build-lexicon              │
     │           mine-source                             ▼
     │                    │                    errors + capability map + lexicon
     │                    ▼                              │
     │            rehearse-transfer (real use)            │
     │                    │                              │
     │             write-artifact (weekly)                │
     │                    ▼                              ▼
     └──── assess-level ◀── review-practice-week ◀────────┘
```

Due lexicon rows come back inside `run-session` and `run-voice-session` — by being **needed**
in a task or a conversation, never by being quizzed.

## The six rules

1. **Learner produces first** — the coach never writes my sentence before I try.
2. **Correct at altitude** — three ranked errors, not thirty.
3. **No evidence, no advance** — a state moves on a linked artifact, not on feeling ready.
4. **No ghost practice** — nothing gets logged that did not happen.
5. **Support language is a tool** — for unblocking, never as the medium.
6. **No debt** — a busy day is a minimum session, never a doubled tomorrow.

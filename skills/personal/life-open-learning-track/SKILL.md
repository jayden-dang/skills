# Open learning track

## Role

REQUIRED: read sibling `ROLE.md` (secretary default, grant rule, hybrid ban, config paths).


## Recipe

1. Set `domain`: life | engineering (user).
2. Create track under `layout.learning_tracks`.
3. REQUIRED: `cadence_per_week`, MS-1 habit, `next_action`, and an empty `weak_points` list for `life-log-learning` to append to.
4. Optional workspace pointer from `roots` (informational only).
5. Registry row.

## Done when

Track note + registry + non-empty next_action.

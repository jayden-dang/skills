# Plan day

## Role

REQUIRED: read sibling `ROLE.md` (secretary default, grant rule, hybrid ban, config paths).


## Recipe

1. Open/create `layout.daily_dir/…` daily note for today.
2. Pull P0s from latest weekly review (PROPOSED or confirmed).
3. Set `focus` to ≤ `limits.max_daily_focus` ids (confirm if contested).
4. Schedule blocks: match `energy: deep` work to deep blocks.
5. **Not today** list (paused, missing workspace, explicit defer).
6. Empty Sessions section + Shutdown checklist.

## Done when

Daily note has focus (≤3), schedule, not-today, shutdown checklist. User executes the work.

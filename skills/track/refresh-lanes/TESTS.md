### Why the skill exists — the user's report

klynt's `lanes.md` was last generated 2026-10-30 (`a13294434`) and was still that file on
2026-11-13, with 17 spec commits — `record delivery` among them — landed under it. Nothing
but the user-invoked `/chart-progress` ran `lanes.py`, and no model-invoked skill may invoke
a user-invoked one, nor reach into its folder for the script. So the generator moved here,
and `/chart-progress` calls it.

### Scripts

The move was behavior-preserving first: 70 tests (49 here + 21 in `chart-progress`) green
before and after, with the state labels moved into the snapshot (`labels`) so `render.py`
and `lanes.py` share one home without a cross-folder import. Then, test-first (each failing
on the missing `write_lanes` before it existed):

- off the base branch nothing is written — `not on <base>`. The header carries a fresh
  `Source:` and tracker time on every run, so a copy written on each feature branch would
  conflict at every merge;
- a new tracker reading alone leaves the file — `unchanged`;
- no `## Focus` — `no Focus`;
- the base is `Default PR base:`, else `origin/HEAD`'s branch. The first GREEN fixture wrote
  `Default PR base: main` without the template's `- **…:**` bullet, `project_settings` read
  nothing, and the off-base rule silently never applied — hence the fallback.

58 tests here, 21 in `chart-progress`, all green.

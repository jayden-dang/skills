# Personal OS templates

Seed notes for a Personal OS vault. Used by `life-setup` and by humans who prefer manual setup.

| File | Entity |
|---|---|
| `inbox-item.md` | Capture |
| `daily.md` | Daily plan / log |
| `weekly-review.md` | Weekly review |
| `quarterly-review.md` | Quarterly review |
| `project.md` | Project (outcome + light roadmap) |
| `area.md` | Life area (ongoing standards) |
| `learning-track.md` | Learning pipeline |
| `session-log.md` | Focus session log |

Placeholders such as `{{date}}`, `{{slug}}`, `{{title}}` are for Templater or manual replace.

Paths and folder names always come from the vault **config** after setup — these files do not assume a fixed absolute location on disk.
